# Stereo_BM — измерение расстояния по стереопаре

Проект на Python и OpenCV для калибровки двух камер, ректификации изображений и оценки расстояния методом блочного сопоставления **StereoBM**. Содержит отдельные версии для Windows и Linux / Raspberry Pi.

Программа показывает изображения камер и карту диспаратности, измеряет расстояние в небольшой области кадра и сохраняет статистику экспериментов в CSV.

## Возможности

- Определение индексов подключённых камер.
- Сохранение пар фотографий шахматной доски.
- Калибровка каждой камеры и стереопары.
- Ректификация: выравнивание соответствующих точек по горизонтали.
- Численная проверка вертикального расхождения по углам шахматной доски.
- Измерение расстояния по медиане диспаратности в области 31 × 31 пиксель.
- Сбор 50 валидных измерений с расчётом среднего, стандартного отклонения и ошибки относительно заданного расстояния.
- Вывод скорости обработки и времени отдельных этапов.

## Требования и установка

Нужны Python 3, NumPy, OpenCV с поддержкой графических окон, две камеры и шахматная доска. Для Linux используется интерфейс V4L2. Для просмотра окон требуется графическая сессия; пакет opencv-python-headless для этих сценариев не подходит.

Зависимости перечислены в requirements.txt.

### Windows

Откройте PowerShell в распакованной папке Stereo_BM:

```powershell
py -m venv .venv
./.venv/Scripts/python.exe -m pip install numpy opencv-python
cd stereo_project_win
../.venv/Scripts/python.exe camera_index_check.py
```

В командах ниже под python понимается интерпретатор этого окружения. Без активации окружения используйте вместо python путь ..\.venv\Scripts\python.exe.

### Linux / Raspberry Pi

Откройте терминал в распакованной папке Stereo_BM:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install numpy opencv-python
cd stereo_project_lin
python camera_index_check_linux.py
```

Доступность готового пакета OpenCV зависит от ОС, архитектуры и версии Python. Если установка не проходит, потребуется совместимая сборка OpenCV для вашей системы.

**Выполняйте дальнейшие команды из папки своей платформы.** Многие скрипты читают и записывают файлы относительно текущей рабочей папки.

## Порядок работы

### 1. Определите камеры и согласуйте их порядок

Закройте другие программы, использующие камеры, и запустите camera_index_check.py либо camera_index_check_linux.py. Скрипт проверяет индексы от 0 до 5. Поочерёдно закрывайте объективы, чтобы определить физическую левую и правую камеры.

- Пробел — следующая камера.
- Q или Esc — завершить проверку.

### 2. Снимите калибровочные пары

В stereo_calibrate.py или stereo_calibrate_linux.py проверьте:

```python
CHECKERBOARD = (9, 6)
SQUARE_SIZE = 24.0  # миллиметры
```

9 × 6 — количество **внутренних углов**, то есть доска из 10 × 7 клеток. SQUARE_SIZE должен соответствовать фактически измеренной стороне клетки. От этого зависит масштаб вычисляемого расстояния.

Запустите скрипт своей платформы:

```powershell
# Windows
python capture_calibration.py
```

```bash
# Linux
python capture_calibration_linux.py
```

Нажимайте S, чтобы сохранить пару, и Q для выхода. Снимки записываются как calibration_photos/left/00.jpg и calibration_photos/right/00.jpg, затем 01.jpg и т. д.

Снимайте доску в разных положениях, наклонах и частях кадра; она должна быть видна обеим камерам. Для продолжения калибровки код требует минимум 10 пар с обнаруженными углами на обоих изображениях.

**При каждом запуске нумерация начинается с 00: существующие снимки с такими именами перезаписываются.** Перед новой серией перенесите предыдущие снимки в отдельную папку. Имена и порядок файлов слева и справа должны соответствовать: калибратор сопоставляет отсортированные списки файлов.

Сохраняйте одинаковое разрешение камер при съёмке, ректификации и измерении. Скрипты съёмки и просмотра ректификации не задают разрешение явно; при необходимости добавьте его настройку в код.

### 3. Выполните калибровку

```powershell
# Windows
python stereo_calibrate.py
```

```bash
# Linux
python stereo_calibrate_linux.py
```

Скрипт выводит ошибки калибровки, матрицы камер, взаимный поворот R, перенос T и расчётное расстояние между оптическими центрами камер. Результат сохраняется в stereo_calibration.npz, заменяя существующий файл.

Файл содержит K_left, D_left, K_right, D_right, R, T, E, F и image_size. При задании SQUARE_SIZE в миллиметрах вектор T также выражен в миллиметрах.

В диагностическом выводе базовое расстояние сравнивается с фиксированными **100 мм**. Это значение исходной установки, а не универсальное требование; для своей установки измените диагностическое сравнение. Измеритель берёт геометрию из калибровки.

### 4. Проверьте ректификацию

```powershell
# Windows
python stereo_rectify.py
```

```bash
# Linux
python stereo_rectify_linux.py
```

В окне показываются два выровненных изображения с горизонтальными линиями. Соответствующие точки должны находиться примерно на одной высоте. S сохраняет rect_left.png и rect_right.png без нарисованных направляющих, Q завершает работу. Сохранение заменяет предыдущую пару.

Для численной проверки сохраните пару с полностью видимой шахматной доской:

```powershell
# Windows
python check_rectification.py rect_left.png rect_right.png --cols 9 --rows 6
```

```bash
# Linux
python check_rectification_linux.py rect_left.png rect_right.png --cols 9 --rows 6
```

Проверка выводит среднюю, медианную, RMS и максимальную вертикальную ошибку в пикселях, а также медианную диспаратность. Оценка относится к найденным углам этой пары, а не ко всему полю зрения. Если скрипт предупреждает о возможном обратном порядке углов, сначала проверьте их соответствие визуально.

### 5. Запустите измерение

**Windows:** задайте REAL_DISTANCE_CM в stereo_bm_win.py равным известному расстоянию до объекта в сантиметрах. По умолчанию установлено 100.0.

```powershell
python stereo_bm_win.py
```

**Linux / Raspberry Pi:** реальное расстояние можно передать при запуске; по умолчанию это 60 см.

```bash
python stereo_bm_linux.py --left /dev/video0 --right /dev/video2 --distance 60
```

Дополнительные параметры Linux:

| Параметр        | Назначение                                                 |
| --------------- | ---------------------------------------------------------- |
| --left, --right | Пути к устройствам камер                                   |
| --distance      | Известное расстояние до объекта в см, больше нуля          |
| --calibration   | Путь к файлу NPZ; по умолчанию рядом со скриптом           |
| --results       | Путь к CSV; по умолчанию рядом со скриптом                 |
| --fourcc        | YUYV или MJPG; ограничение текущей реализации описано ниже |

Разместите объект в красной области измерения. Нажмите S: программа соберёт 50 валидных измерений и добавит строку в CSV. Во время сбора держите объект и камеры неподвижными. Q завершает работу; незаконченная серия в CSV не сохраняется.

Клавиши работают в активном окне OpenCV; используйте латинскую раскладку без Shift.

## Как вычисляется расстояние

После ректификации StereoBM рассчитывает горизонтальное смещение соответствующих точек — диспаратность. В области 31 × 31 пиксель отбрасываются неподходящие значения. Если осталось не менее 50 пикселей, берётся медиана диспаратности и вычисляется:

```text
Z_cm = f_px × B_mm / (10 × |d_px|)
```

Здесь f — фокусное расстояние из матрицы ректифицированной камеры, B — модуль горизонтальной базы из проекционных матриц, d — медианная диспаратность. Результат представляет глубину вдоль оптической оси ректифицированной камеры.

REAL_DISTANCE_CM / --distance используется только для расчёта ошибки эксперимента, а не для настройки измеренной глубины.

### Основные параметры текущего кода

| Параметр                | Windows    | Linux             |
| ----------------------- | ---------- | ----------------- |
| MIN_DISPARITY           | 0          | -160              |
| NUM_DISPARITIES         | 256        | 160               |
| BLOCK_SIZE              | 15         | 15                |
| ROI_RADIUS              | 15         | 15                |
| MIN_VALID_PIXELS        | 50         | 50                |
| NUM_SAMPLES             | 50         | 50                |
| Центр области измерения | (320, 240) | Центр изображения |

Windows-версия настроена на положительную диспаратность, Linux-версия — на отрицательную. Это настройки конкретной стереопары, а не требования операционной системы. При изменении порядка камер или геометрии проверьте диапазон поиска и фильтр valid_disparities. Параметры задаются в исходном коде.

## Результаты экспериментов

Windows сохраняет bm_results_optimized.csv в текущую папку. Linux по умолчанию сохраняет bm_results_optimized_linux.csv рядом со скриптом. Новые серии дописываются в конец файла; одна строка соответствует одной серии из 50 валидных измерений.

| Поле CSV               | Значение                                              |
| ---------------------- | ----------------------------------------------------- |
| real_distance_cm       | Заданное реальное расстояние, см                      |
| measured_distance_cm   | Среднее измеренное расстояние, см                     |
| std_cm                 | Стандартное отклонение измерений, см                  |
| mean_disparity_px      | Средняя диспаратность по серии, пиксели               |
| absolute_error_cm      | Модуль разницы среднего и реального расстояния, см    |
| relative_error_percent | Относительная ошибка, %                               |
| valid_percent          | Средняя доля валидных пикселей в области измерения, % |
| processing_time_ms     | Среднее время вызова StereoBM, мс                     |
| algorithm_fps          | Обратная величина среднего времени StereoBM, кадры/с  |

algorithm_fps не включает захват кадров, подготовку и отображение. Общая частота работы показывается отдельно как FPS.

## Особенности и устранение проблем

- **Камера не открылась.** Закройте приложения, использующие камеру, повторно проверьте индексы и подключение. В Linux проверьте доступ к нужным устройствам /dev/videoN.
- **Размер кадров не совпадает с калибровкой.** Настройте камеры на разрешение калибровочных снимков либо заново выполните калибровку с нужным разрешением.
- **NO DATA или сбор серии не завершается.** Недостаточно валидных пикселей. Проверьте освещение, резкость, текстуру объекта, качество ректификации, порядок камер и диапазон диспаратности. Однородная поверхность может не давать устойчивых соответствий.
- **Неверный масштаб расстояния.** Проверьте реальный размер клетки и единицы SQUARE_SIZE: измеритель ожидает миллиметры. После изменения положения камер нужна новая калибровка.
- **Не найдена шахматная доска.** Проверьте число внутренних углов, фокус и видимость всей доски на обоих кадрах.
- **Параметр --fourcc в Linux.** Хотя аргумент принимает YUYV и MJPG, далее код повторно устанавливает MJPG. Фактический формат выводится при запуске; для полноценного выбора YUYV потребуется убрать повторную установку MJPG в stereo_bm_linux.py.
- **Область измерения в Windows.** Центр жёстко задан как (320, 240), что соответствует центру изображения 640 × 480. Для другого разрешения скорректируйте center_x и center_y.

Захват использует последовательные grab/retrieve двух камер; аппаратная синхронизация в коде не реализована. Быстрое движение может ухудшать соответствие стереопары.
